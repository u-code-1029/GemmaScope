# GemmaScope

EmbeddingGemma 2를 사용하는 로컬 SEM·TEM 이미지 학습·검색 데스크톱 앱입니다. 한국어 UI, macOS Apple Silicon과 Windows x64를 대상으로 합니다. 파일과 학습 데이터는 외부에 업로드하지 않습니다. 최초 패키지·공개 모델 다운로드에는 인터넷이 필요합니다.

## 실행

Windows x64 설치 파일은 [GitHub Releases](https://github.com/u-code-1029/GemmaScope/releases)에서 로그인 없이 다운로드합니다. **GemmaScope-Setup-0.2.0-x64.exe**를 실행해 설치하세요. Python은 포함되어 있으며 최초 실행 시 앱에서 학습 패키지를 설치합니다.

이 작업 폴더에서는 `Launch GemmaScope.command`를 더블클릭하면 준비된 학습 환경으로 실행됩니다. Mac Apple Silicon 설치 파일은 `release/GemmaScope-0.1.0-arm64.dmg`입니다. 설치본은 별도 데이터 폴더를 사용하므로 처음 실행할 때 아래의 학습 환경 설치가 필요합니다. 개발용 설치 파일로, 서명·공증은 되어 있지 않습니다.

```sh
npm ci
npm start
```

개발 실행에는 Node.js 24 및 Python 3.12 이상이 필요합니다. `GEMMASCOPE_PYTHON`으로 Python 실행 파일을 지정할 수 있습니다. 배포 설치 프로그램은 Python 런타임을 포함합니다.

1. 앱의 **실행 환경 → 학습 환경 설치**에서 전용 Python 환경을 준비합니다. 시스템 Python 패키지는 변경하지 않습니다.
2. 프로젝트 폴더를 선택하고 **이미지 가져오기**로 원본 폴더를 등록합니다.
3. `SEM / TEM / 기타`를 라벨링하고 **시료 그룹**을 지정합니다. 같은 시료의 서로 다른 배율·프레임은 같은 그룹으로 묶으세요.
4. **학습 스튜디오**에서 분류기 학습 또는 마지막 두 블록 미세조정을 실행합니다.
5. **검색·검증**에서 완료된 모델을 선택하고 **색인 만들기**를 실행합니다. 이후 문장·시료명·날짜로 검색합니다.

프로젝트 원본 이미지는 수정하지 않습니다. 썸네일·정규화 이미지·라벨·모델은 선택한 프로젝트에 저장합니다. 개발 실행의 기본 데이터 위치는 `.gemmascope/`이며 배포 앱은 OS의 앱 데이터 디렉터리를 사용합니다. 외장 드라이브를 다시 연결하거나 다른 컴퓨터로 프로젝트를 옮겼다면 원본 루트를 다시 연결합니다.

## 이미지 선택·제거와 단축키

- 클릭은 한 장 선택, Ctrl+클릭(Mac: ⌘+클릭)은 추가·해제, Shift+클릭은 연속 범위 선택입니다. 이미지의 체크박스로도 여러 장을 선택할 수 있습니다.
- **Delete 또는 우클릭 → 데이터셋에서 제거**로 선택 이미지를 제외합니다. 원본 파일·라벨·메타데이터·기존 학습 기록은 보존되며 이후 학습과 검색에서 제외됩니다. 이미 학습한 모델의 가중치를 되돌리지는 않습니다.
- **Ctrl+Z(Mac: ⌘+Z)** 또는 알림의 **실행 취소**로 최근 제거를 되돌립니다. 앱을 다시 열어도 **제외한 이미지** 탭에서 복원할 수 있습니다. 재가져오기만으로 자동 복원하지 않습니다.
- 방향키로 이동, Shift+방향키로 범위 선택, Space로 선택 토글, Enter·더블클릭으로 정보·미리보기를 엽니다. `1 / 2 / 3 / 0`은 SEM / TEM / 기타 / 라벨 해제입니다.
- Ctrl+A는 **현재 페이지** 전체 선택, Ctrl+F는 검색창으로 이동, Shift+F10은 이미지 메뉴, Esc는 창·메뉴 닫기 또는 선택 해제입니다. 입력창 안에서는 일반 텍스트 편집 단축키가 우선됩니다.
- 상단 **사용 안내** 또는 **F1**에서 모든 단축키를 확인할 수 있습니다. 제거·복원·라벨 편집은 가져오기·학습·색인 작업이 끝난 뒤 가능합니다.

## 지원 데이터

- PNG/JPEG/TIFF/BMP/WebP/GIF, DM3/DM4, SER/EMI, MRC의 2D 영상 및 식별 가능한 영상 스택.
- 16비트/실수 이미지는 min–max 정규화한 RGB 사본으로 처리하며 전처리 정보를 기록합니다.
- 스택 프레임은 **0부터 시작하는 포함 범위**를 선택합니다. 기본은 첫 프레임(0–0)입니다. 전체 스택이 자동 검사된 것으로 해석하지 마세요.
- STEM·HAADF 실공간 영상은 TEM에 포함합니다. 회절패턴·스펙트럼·그래프는 기타로 라벨링합니다.
- 4D-STEM, 스펙트럼 데이터와 3D 볼륨은 자동 변환하지 않고 건너뜁니다. 형식/장비 버전에 따라 읽을 수 없는 파일은 이유를 표시합니다.
- 메타데이터 CSV: UTF-8, `path,frame,sample,acquired_at,magnification,voltage_kv,description`. `path` 필수, `frame` 생략 시 0. 상대 경로는 CSV 파일 폴더 기준입니다. 촬영일은 `YYYY-MM-DD` 또는 ISO 날짜입니다.

## 학습과 검색의 의미

**분류기 모드**는 원본 모델을 고정하고 768차원 이미지 임베딩 위에 3분류 로지스틱 회귀를 학습합니다. **미세조정 모드**는 마지막 두 언어 Transformer 블록 및 최종 norm/projection의 실제 모델 가중치를 이미지 triplet으로 변경합니다. 전체 가중치를 학습하는 기능은 아닙니다. SEM/TEM을 anchor로 삼고 다른 시료의 같은 클래스 영상을 positive, 반대 클래스와 기타 영상을 negative로 사용합니다.

데이터는 시료 그룹 단위로 학습·검증·시험으로 분리합니다. 분류기는 각 클래스 최소 3개 독립 그룹, 미세조정은 SEM/TEM 각각 최소 4개 독립 그룹(기타 3개)이 필요합니다. 이는 실행 최소 조건이며 정확도를 보장하는 데이터량이 아닙니다. 클래스 폴더 하나를 시료 그룹 하나로 둔 채 학습하지 말고 실제 시료 단위로 수정하세요.

통과 기준은 검증셋에서 기타 오탐을 줄이도록 선택하고 시험셋 결과를 별도로 표시합니다. 기본 시작 기준은 0.95입니다. 점수는 **정확도 보증이나 보정된 확률이 아닙니다**. 기타 오탐이 0인 작은 시험셋도 미지 이미지에서 오탐 0을 보장하지 않습니다. 통과 이미지가 0개면 정밀도는 계산 불가로 표시됩니다.

검색 후보는 먼저 SEM/TEM 판별을 통과해야 합니다. 수동으로 기타 라벨을 붙인 이미지는 즉시 제외됩니다. 그 뒤 **변경하지 않은 원본 모델**의 문장·이미지 임베딩으로 순위를 계산하고 파일명/메타데이터 키워드 검색과 결합합니다. 미세조정된 이미지 벡터와 원본 텍스트 벡터를 혼합하지 않습니다. 원본 변경·삭제, 다른 모델, 오래된 색인은 재검사를 요구합니다.

이미지 수 최대 100,000개/프로젝트. 색인은 디스크에 배치별 저장하며 취소 후 다시 시작하면 완료된 항목을 재사용합니다. 모델 다운로드 중 취소는 다운로드 호출이 반환된 뒤 적용될 수 있습니다. 앱 종료 후 전체 학습을 이어서 재개하는 기능은 제공하지 않으며, 색인 재개와 구분됩니다.

## 장치와 설치

- Mac: MPS 우선, CPU 수동 선택 가능. float32 사용. 기본 배치 1, 누적 8.
- Windows: NVIDIA GPU 감지 시 공식 CUDA 13.0용 PyTorch를 설치합니다. 호환 드라이버가 필요하며 GPU 미인식 시 CPU를 선택할 수 있습니다.
- CUDA bf16 지원 시 bfloat16, 그 외 float32. EmbeddingGemma 2에는 float16을 사용하지 않습니다.
- 실제 첫 미세조정 스텝으로 메모리/역전파를 점검합니다. 메모리 부족 시 배치 1, 다른 앱 종료 또는 분류기 모드를 안내합니다.
- 모델 첫 다운로드와 학습 환경은 수 GB의 디스크 공간을 사용합니다. 미세조정 실행마다 별도의 encoder 가중치를 저장합니다.

## 설치 프로그램 빌드

각 운영체제에서 독립적으로 빌드하세요. 깨끗하고 재배치 가능한 Python 3.12+ 배포본(`venv`, `ensurepip` 포함)을 준비합니다. 예: `uv python install 3.12` 후 해당 인터프리터의 `sys.base_prefix` 디렉터리.

```sh
npm run runtime:prepare -- --from /path/to/standalone/python
npm run dist:mac
# Windows에서:
npm run dist:win
```

결과는 `release/`에 생성됩니다. `.github/workflows/build.yml`은 Windows에서 테스트, 설치 프로그램 생성 및 패키지 시작을 검증하는 CI 구성입니다. 수동 실행 또는 `v`로 시작하는 태그를 올려 실행합니다. 기본 빌드는 서명/공증되지 않습니다. 서명된 배포에는 개발자 인증서가 별도로 필요합니다.

## 검증

```sh
npm test
.gemmascope/venv/bin/python3 -m unittest discover -s tests -p 'test_*.py' -v
```

테스트 데이터는 임시 생성된 픽셀과 모의 임베딩이며 SEM/TEM 정확도 증거가 아닙니다. 실제 모델의 인코딩·미세조정 및 플랫폼별 검증 내역은 `VALIDATION.md`에 기록합니다.
